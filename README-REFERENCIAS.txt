REFERENCIAS PARA CODEX - INVITACIÓN WEB DE CUMPLEAÑOS

Archivos:
- design/invitacion-original.png: invitación original con foto y datos.
- design/mockup-aprobado.png: diseño visual aprobado de tres pantallas móviles.
- public/assets/images/cumpleanera.webp: recorte provisional de la foto desde la invitación original.

Descomprime el ZIP en la raíz del repositorio. Las carpetas design/ y public/assets/images/ deben quedar allí.

IMPORTANTE: El recorte procede de una imagen compuesta y no sustituye una fotografía original de calidad. Cuando esté disponible, reemplazar public/assets/images/cumpleanera.webp por la fotografía original sin modificar los rasgos.
No utilizar mockup-aprobado.png como fondo de pantalla ni como interfaz estática: es una guía de diseño para implementar HTML/CSS accesible.
